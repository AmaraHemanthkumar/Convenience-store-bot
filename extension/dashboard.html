Convenience Store Bot

1. Load barcodes

Choose one or more Excel/CSV files or supplier invoice PDFs. Each file becomes one row below – click it to open the whole sheet. Open one and work on it while the others are looked up in the background.

2. Prices

New items: highest supermarket price + markup $ + markup %. Items already in PosPort are flagged if less than $1.50 or more than $2.00 above.

3. Save to PosPort

Each file row has its own buttons too. For items already in PosPort you can change the price and the name – tick the row and save.

1. Shopping list or invoice

Supplier invoice PDFs are read automatically (cost per unit inc GST, units delivered, short/out of stock). Excel/CSV too – then pick the columns.

2. Compare

Happens by itself when you load a file: today's Woolworths and Coles price including specials, whether the item is in PosPort (and at what price), and your margin. Use the button to check again.

Back up all Back Office data

The bot opens every page in the Back Office menu (catalog, categories, modifiers, customers, inventory, settings…), goes through all their pages, and saves everything it sees – plus the full data the Back Office loads behind the scenes.

You get one Excel file (a sheet per section) and one JSON file with every record and field – the format another POS system or a developer can import. It only reads; it never changes anything.
